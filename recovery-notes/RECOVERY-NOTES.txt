This is NOT a repo clone. Files were rebuilt from the text of file writes and file reads that were recorded before the GitHub account was suspended. No Git history, no binary files (icons, images, keystores).
Status per file is in MANIFEST.csv:
- READ-VERIFIED: matches a full read of the file at the date shown.
- EXACT-WRITE: a complete write at the date shown, no later edit found in the records.
- EDITED-APPLIED: a complete write plus simple later edits that were re-applied by pattern. Not byte-checked.
- STALE-LATER-EDITS-NOT-APPLIED: later edits exist but could not be re-applied. The file is an older version than the last release.
